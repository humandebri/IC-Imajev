# Inference runtime

The dependency direction is `canisters/inference → imajev-runtime → inference-core`. Python clients and the browser frontend prepare model inputs and orchestrate execution.

Read the [architecture and numerical contracts](ARCHITECTURE.md), [inference-core guide](../../crates/inference-core/README.md) and [canister API](../CANISTER_API_NAMES.md). Historical extraction, optimization and measurement notes are preserved in the [experiment archive](../ARCHIVE.md).
